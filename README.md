# Minecraft Bedrock Pistol Add-On

Blockpow Arsenal is a Minecraft Bedrock add-on with a craftable custom pistol that fires arrow projectiles. It includes behavior and resource packs, a pistol item and texture, a crafting recipe, and a firing cooldown.

## Install

1. Run `python package_addon.py` from the project directory. Python 3 is required; no extra packages are needed.
2. Import the generated `FieldArms.mcaddon` into Minecraft Bedrock.
3. In world settings, activate both the Field Arms Behavior Pack and Field Arms Resources pack.

## Use

1. Enter a world with both packs enabled.
2. Craft the Field Pistol at a crafting table using this pattern, with `I` as an iron ingot and `S` as a stick:
   ```
    II
    SI
   S
   ```
3. Use the pistol to fire an arrow projectile. Firing has a 0.35-second cooldown.
